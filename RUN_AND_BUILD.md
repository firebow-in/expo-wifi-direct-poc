# Run & Build — Wi‑Fi Direct POC

> ℹ️ **Note:** For the complete open-source project overview, architecture diagrams, wire protocol specs, and API reference, see [README.md](README.md).

This project is an **Expo (React Native) app** with a custom native module `expo-wifi-direct` for Android Wi‑Fi Direct. The following steps get the POC running and building.

## Before adding to Git

The repo **`.gitignore`** already excludes these, so you don’t need to delete them before `git add`:

- `node_modules/`
- `android/build/`, `android/app/build/`, `android/.gradle/`
- `ios/build/`
- `.gradle/`
- `dist/`, `build/`
- `.expo/`
- `logs/`, `*.log`
- `.env`, `.env.*`

Just run `git add wifi-direct/android-wifip2p-feb-26` from the tech-pocs root; these paths will be ignored.

---

## 1. Restore what was missed by copy

- **`node_modules`** (including `react`, etc.) → run **`npm install`** in this folder.
- **`android/`** (launcher, splashscreen, etc.) → generated by **`npx expo prebuild`** (see below). You don’t need to copy the original `android` folder.

So: **install deps** and **run prebuild** once. After that, run or build as needed.

## 2. One-time setup

From the **project root** (this folder: `android-wifip2p-feb-26`):

```bash
npm install
npx expo prebuild --platform android
```

- `npm install` restores all JS dependencies (including React).
- `npx expo prebuild` generates the `android/` project (and native assets like launcher/splash). If you already have `android/`, it will reuse/update it.

## 3. Run on a device or emulator

- Connect an Android device with USB debugging, or start an Android emulator.
- Then:

```bash
npm run android
# or
npx expo run:android
```

If you see “No Android connected device found”, connect a device or start an emulator from Android Studio (AVD Manager).

## 4. Build a release APK

From the project root:

```bash
cd android
.\gradlew.bat assembleRelease
```

Release APK will be at:

- `android\app\build\outputs\apk\release\app-release.apk`

Install on a device:

```bash
adb install android\app\build\outputs\apk\release\app-release.apk
```

## 5. Avoid “Destination path too long” next time

- **Option A:** Enable long paths in Windows (run PowerShell as Administrator):
  ```powershell
  New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force
  ```
  Then reboot. After that, copying this project to long paths is less likely to fail.

- **Option B:** Keep the project in a **short path**, e.g. `D:\wd` or `C:\poc`, so the full path to deep folders stays under 260 characters.

## 6. Quick verification

- **Dependencies:** `npm install` completed without errors.
- **Prebuild:** `npx expo prebuild --platform android` finished and created/updated `android/`.
- **Run:** `npm run android` works when a device/emulator is connected.
- **Release:** `cd android && .\gradlew.bat assembleRelease` produces `app-release.apk`.

If any step fails, fix the reported error (e.g. JDK, Android SDK, or path length) and retry.
